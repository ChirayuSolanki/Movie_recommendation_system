Movie Recommendation System
This repository contains a simple movie recommendation system built using the TMDB 5000 Movies and Credits datasets. The system uses Natural Language Processing (NLP) techniques and the TF-IDF vectorizer from the sklearn library to generate movie recommendations based on a movie's metadata.

Datasets
The datasets used are:

tmdb_5000_movies.csv
tmdb_5000_credits.csv
These datasets include various details about movies such as genres, keywords, cast, crew, and overviews.

Requirements
The following Python libraries are required to run the code:

pandas
numpy
nltk
sklearn
